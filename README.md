🍽️ Restaurant Management System (MERN Stack)

A full-stack Restaurant Management Web Application built using MongoDB, Express.js, React.js, and Node.js (MERN).
It allows admins to manage menu items, chefs, tables, and orders, while guests can place and track their food orders in real time.

🚀 Live Demo
Frontend (Guest App): https://restaurant-management-67vp.vercel.app/
Frontend (Admin App): https://restaurant-management-ochre-mu.vercel.app/

🛠️ Tech Stack
Layer	Technology
Frontend	React.js, Axios, React Router, TailwindCSS / CSS
Backend	Node.js, Express.js
Database	MongoDB Atlas
Image Uploads	Multer
Hosting	Vercel (Frontend) & Render (Backend)

✨ Features
👩‍💼 Admin Panel
Add, update, and delete menu items.
View and manage orders, tables, and chefs.
Track which chef is assigned to which order.
Mark orders as completed or in-progress.

🧑‍🍽️ Guest Interface

Browse all available menu items (with images, descriptions, and prices).
Place orders with custom quantity and order type (Dine-in / Takeaway).
See total bill and estimated preparation time.

⚙️ Backend

RESTful API with full CRUD operations.
Integrated CORS policy for multiple frontend domains.
Organized routes for menu, orders, chefs, and tables.
MongoDB models with relationships between orders, chefs, and tables.
